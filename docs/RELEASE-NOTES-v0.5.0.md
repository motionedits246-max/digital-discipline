# Digital Discipline 0.5.0

- The Daily Planner adds timed blocks, a weekly review, and targets for observed activity, completed tasks, and confirmed reading. Activity History supports corrections, undo, and separate manual entries.
- Earned entertainment exchanges observed work time for a browser leisure budget. Optional short-feed interventions progress from a pill hint to a timed restriction. Quiet hours apply across the desktop and browser companion.
- Reusable focus presets and Ctrl+K actions make common controls easier to reach. Strict presets can minimize selected Windows apps once per session.
- Passphrase-encrypted backups support restore previews, recovery copies, and optional daily backups. Opt-in desktop sync transfers encrypted activity through an owner-selected shared folder.
- Resource health shows measured agent and desktop host usage and exports aggregate diagnostics. The update panel checks the published version and verifies the installer download before saving it.

Windows x64 installer. Browser companion 0.4.0, local protocol 1.0. Development signing uses a self-signed certificate. Updates are installed manually.

Desktop sync currently covers Windows activity. Learning Mode exceptions use selected YouTube video IDs. Android tracking and automatic playlist or channel exceptions remain open.
