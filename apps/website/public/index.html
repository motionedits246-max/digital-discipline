Privacy

On your PC.
In your hands.

Activity stays local by default

The Windows agent writes foreground and idle history to SQLite on your device. The activity database is not fully encrypted.

You connect the browser

Pair a profile and enable activity recording to include video observations. The companion talks to the agent over a local connection.

You choose when AI is involved

Bring your own provider key for optional AI. Public metadata lookups have a separate opt-in, and remote classification needs approval for each service.

Windows setup

Start on
your desktop.

Version 0.4.3 is a development build for Windows x64. Sign in to GitHub with an account that can access the private repository.

Open Windows build ↗

  1. Get the development bundle

    Download the v0.4.3 artifact from the successful run. Check the installer hash against the build record. The installer uses a self-signed development certificate.

  2. Open your workspace

    Run the x64 setup file from the extracted bundle. Open the workspace from the floating controller or system tray.

  3. Add your browser if you want it

    In Browser setup, open the companion folder. In Brave or Chrome, enable Developer mode and choose Load unpacked. Authorize the extension ID, then opt in to recording.

Common questions

Can I use it without the extension?

Yes. Windows app and idle tracking work independently. The companion adds browser playback observations and restrictions.

Will it block desktop apps?

Selected native apps can trigger a warning. The browser companion enforces site and path restrictions.

Does the AI coach need a key?

Yes. Configure your own provider key for the coach. Activity history and focus sessions work independently.

Where can I follow development?

The implementation ledger lists shipped work, test evidence and features awaiting acceptance.
